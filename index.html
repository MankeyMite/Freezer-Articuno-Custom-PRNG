Articuno PRNG Freezer Generator

Generates the raw 80-byte Articuno payload and 14 WELDR/Base64 box names for E-Sh4rk's Freezer setup. This version loads any 32-bit frozen seed from a literal, writes it to Emerald's PRNG state at 0x03005D80, then returns with bx r0.

Original Freezer code by E-Sh4rk. Articuno PRNG seed payload modified by MankeyMite.

Input

Decimal values can be typed normally. Hex values should use 0x.

Based on the static encounter test, 1 gives frozen seed → one advance → reported Origin Seed. If another method has a consistent offset, adjust this value.
